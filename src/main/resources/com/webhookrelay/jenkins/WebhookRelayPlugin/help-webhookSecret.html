Optional shared secret for webhook signature verification. Enter the same value as the secret (GitHub, Bitbucket, Gitea) or secret token (GitLab) on the repository webhook.

When set, saving this page (or clicking Get Webhook URL) creates a Webhook Relay Function named jenkins-<preset>-signature-check-<bucket>, stores the secret in its WEBHOOK_SECRET config variable and attaches it to every input of the configured bucket(s). Requests whose signature does not match are answered with 401 by Webhook Relay and are never forwarded to Jenkins.

  • GitHub: X-Hub-Signature-256: sha256=<HMAC-SHA256 of body>
  • Bitbucket Cloud: X-Hub-Signature: sha256=<HMAC-SHA256 of body>
  • Gitea / Forgejo: X-Gitea-Signature: <HMAC-SHA256 of body>
  • GitLab: X-Gitlab-Token must equal the secret

Not available for the Generic Webhook Trigger and Custom presets. If an input already has a function you attached yourself, it is left untouched and an error is shown.

Clearing the secret detaches the verification function from the bucket's inputs on the next save (the function itself is kept, unused).
